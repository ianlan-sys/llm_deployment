# 本地大模型私有化部署方案（local-llm-demo）

Sep 29, 2026 · 负责人 @ian

> 面向某企业「数据不出内网 + 最高保密要求 + 信创合规」的本地大模型平台落地方案。**50 万元为项目全部经费**（含服务器硬件、实施与维保），目标是在满足要求的前提下尽量提高我方毛利。

## 一、执行摘要

**结论：现有 VPS 只是演示/售前环境，不能作为交付给客户的生产系统；生产由我方提供一台国产 GPU 一体机（应用与推理同机部署、国产 OS、物理隔离内网）。按经济型配置，预计成本约 22–30 万元，毛利约 20–28 万元（40–56%）。**

- **应用软件已就绪。** `local-llm-demo` 是一套架构正确的本地化平台（FastAPI + 前端 + 内置 Ollama，全部容器化，数据存本地 SQLite 与本地卷），已实现坐席辅助、运维知识问答、文档审核三条业务流。它目前运行在“演示模式”（离线、可复现、无需真实模型），因此能跑在这台无 GPU 的小机器上。
- **缺的是算力。** 当前 VPS 为 2 核 / 8GB、**无任何 GPU**，只能跑演示。要接入真实模型、满足 20–40 并发，必须部署独立的国产 GPU 服务器，用 vLLM-Ascend / MindIE 提供 OpenAI 兼容推理服务，再把应用切到 `real` 模式指向它。
- **推荐硬件（信创合规，经济型）：** 一台鲲鹏 / 海光 CPU 服务器 + **2×华为 Atlas 300I Duo 96G** 推理卡（预留扩到 4 卡的槽位），预装银河麒麟 V10。主力模型选 **Qwen3.6-35B-A3B（MoE，激活约 3B，对慢显存带宽友好）**，RAG 增配国产嵌入模型（bge-m3）。硬件预算约 **10–14 万元**；POC 压测不达标时再加卡。
- **演示环境：** Demo 已打包为**离线安装包**（x86\_64 与 ARM64 两种架构），可在国产 OS 上无外网一键部署，用于售前演示。
- **演示 VPS 的安全收敛：** 防火墙未开、端口对 0.0.0.0 全开、root 曾以明文口令经微信传递，需要收敛。同机的 `everlink-api` 按属主决定**不做改动**，不在本项目范围内。
- **关键关卡：** 300I Duo 在 vLLM 上仍属**实验性支持**，采购前必须先做一轮真实模型压测，达标再下单。

## 三、目标与需求

**业务目标**

- 将坐席辅助、运维知识问答、文档审核三条业务流从“演示模式”切换为真实模型驱动，在客户内网以 Web 形式稳定运行。
- **保密要求为最高级别**：所有数据（对话、上传文档、知识库、日志）不出内网，推理不依赖任何外部服务，系统部署在物理隔离网络中。
- 信创：国产 CPU、国产 AI 加速卡，**必须使用国产操作系统**，已确定采用银河麒麟 V10。

**已确认的需求**

| 项 | 客户确认 |
| --- | --- |
| 并发 | 20–40 路同时在线请求 |
| 延迟指标 | 客户暂无要求；由我方提出验收基线（见下） |
| 保密等级 | 最高；物理隔离、无外网 |
| 操作系统 | 必须国产 OS |
| 服务器 | 由我方提供，计入 50 万元经费 |
| 身份认证 | 不对接客户统一身份认证；系统自带账号登录，仅内网 Web 访问 |
| 知识库更新 | 每月一次批量更新，无需实时同步 |

**我方建议的验收基线**（客户无明确指标，写入合同以避免验收争议）

- 20 路并发下，首 token 延迟 ≤ 3 s，单路输出速度 ≥ 15 token/s。
- 40 路并发下服务不中断、无报错，允许排队（首 token ≤ 8 s）。
- 以上以 POC 压测结果为准，压测后再定稿。

**功能要求**

| 业务流 | 真实模式下的要求 |
| --- | --- |
| 坐席辅助 | 话术生成、工单摘要 |
| 运维知识问答 | 基于客户内部文档的 RAG 检索问答，回答附来源引用；每月离线批量导入更新 |
| 文档审核 | PDF / DOCX / TXT 上传审核，单文件 ≤ 20 MiB；扫描件需先 OCR |

**非功能要求**

- 可用性：工作时间 99%；支持计划内停机维护。
- 数据保留：SQLite 与上传文件每日备份，至少保留 30 天，备份在内网异机或离线介质保存。
- 审计：登录、模型调用、文档审核结果可追溯（现有审计日志不记录密钥）。
- 人工复核：模型输出仅作辅助，不作为正式审核结论或运维变更指令。

## 四、目标架构

**单机一体化部署**（应用与推理同机，节省一台应用服务器的成本）：

```
          客户物理隔离内网（无外网出口）
┌─────────────────────────────────────────────────────┐
│  用户浏览器 ──HTTPS──▶ Nginx 前端 (:443)              │
│                          │ /api 反代                 │
│  ┌───────────── 国产 GPU 一体机（国产 OS）───────────┐ │
│  │                       ▼                          │ │
│  │   FastAPI 后端（仅容器内部网络）                  │ │
│  │   ├─ SQLite + 上传文件（本地卷）                  │ │
│  │   └─ 向量索引（本地，每月批量重建）               │ │
│  │                       │ OpenAI 兼容 API（本机）   │ │
│  │                       ▼                          │ │
│  │   vLLM-Ascend / MindIE                           │ │
│  │   ├─ 主模型 Qwen3.6-35B-A3B                      │ │
│  │   └─ 嵌入模型 bge-m3                             │ │
│  └──────────────────────────────────────────────────┘ │
└─────────────────────────────────────────────────────┘
```

- **应用层不改代码**：现有后端已支持 `DEMO_PROVIDER_MODE=real`，只需配置 `DEMO_OPENAI_BASE_URL`（指向本机推理服务）、`DEMO_OPENAI_MODEL` 和 `DEMO_OPENAI_API_KEY`（仅后端读取，不进入前端）。
- **网络**：仅前端 443 对用户网段开放；后端、推理服务、Ollama 均不暴露到宿主机端口。
- **离线交付**：所有容器镜像、模型权重、依赖均以离线安装包形式通过审批的介质导入，不在客户现场联网拉取。
- **知识库月度更新**：运维人员每月将新文档通过审批介质导入，执行一次批量重建索引，无需实时同步接口。
- **Ollama 角色**：生产中不承担推理，可保留用于健康检查或移除。
- **演示环境**：售前演示使用离线安装包，可部署在任意国产 OS 设备上（见第九节）；当前 VPS 保持 `demo` 模式，不存放客户真实数据。

## 五、模型选型

| 用途 | 推荐模型 | 理由 |
| --- | --- | --- |
| 主力对话 / 审核 | **Qwen3.6-35B-A3B**（MoE） | 激活参数约 3B，对显存带宽要求低，适合 300I Duo；中文能力强，开源可私有化 |
| 嵌入 / RAG 检索 | **bge-m3** | 国产开源，中文与多语检索效果好，体积小 |
| 备选（资源不足时） | Qwen3 系列 8B–14B 稠密模型 | 部署更成熟，质量略低 |
| 演示 / 联调 | qwen3:1.7b（已打入离线安装包） | 仅供演示与联调，不用于生产 |

**选型原则**

- 许可证允许商用和私有化部署（上线前核对具体版本的许可条款）。
- 采购前用客户真实样本（话术、运维文档、待审文档各 50–100 条）做质量评测和并发压测，达标后再定型。
- 量化方案（W8A8 / W4A16 等）以实测精度和吞吐为准；优先采用 W8A8，在 2 卡上留出足够 KV Cache 支撑 20–40 并发。

5. **知识库月度更新交给客户执行**：我方提供导入脚本与操作手册，维保以远程指导为主。
6. **合同写明验收基线与变更流程**：避免无指标验收带来的反复返工。

## 八、安全与合规

**最高保密要求下的生产措施**

- **物理隔离**：系统部署在客户隔离内网，服务器无外网出口；所有软件、模型、知识库更新均通过经审批的介质离线导入，并做病毒查杀与完整性校验（安装包附 SHA-256 校验值）。
- **等级保护 / 分级保护**：我方具备涉密信息系统集成资质。若系统定为涉密信息系统，按分级保护要求实施并配合测评；若定为非涉密系统，按等保 2.0 三级实施。具体定级与密级需客户确认（见第十节）。
- **访问控制**：不对接客户统一身份认证，使用系统自带账号登录（口令 scrypt 哈希存储、会话密钥随机生成）；仅内网 Web 访问，前端强制 HTTPS。
- **账号与权限**：建议增加多账号及系统管理员 / 安全管理员 / 审计管理员“三员分立”，如为硬性要求需计入实施工作量（当前 Demo 为单账号）。
- **主机加固**：国产 OS 按基线加固；仅开放 443 与受限来源的运维端口；SSH 仅密钥登录；关闭不需要的服务。
- **密钥管理**：推理服务 API Key 仅存于后端 `.env`（权限 600），不进入前端、浏览器或日志。
- **审计与日志**：保留登录、模型调用、审核任务日志；日志不记录密钥和完整敏感原文；日志定期离线归档。
- **备份**：沿用运维手册中的 `backend-data` 卷备份流程，每日定时执行，内网异机或离线介质保存。
- **模型输出**：界面明确标注“AI 辅助，需人工复核”。

**演示 VPS（非交付环境）**

- 启用防火墙，仅放行 SSH（限来源 IP）与 8080；SSH 改为密钥登录并安装 fail2ban；对外长期开放前配置 HTTPS。
- `everlink-api` 按属主决定不做改动。
- 演示 VPS 不存放任何客户真实数据。

**开放问题（需客户确认）**

1. “最高保密要求”对应的是等保三级，还是涉密信息系统分级保护（如是，密级为秘密还是机密）？我方具备涉密资质，但定级会影响安全措施与报价。
2. 是否接受我方提出的验收基线（20 并发首 token ≤ 3 s 等）？
3. 是否要求多账号与“三员分立”？
4. 国产 OS 已确定采用麒麟；具体版本号（V10 的 SP 版本）需与 CANN 驱动兼容列表核对后确认。
5. 机房、上架、供电条件，以及介质导入的审批流程？
